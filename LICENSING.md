# Лицензирование CryptoPro для verifier

Актуальность сведений и цен: **11 августа 2026 года**. Цены приведены по официальной форме заказа КРИПТО-ПРО без НДС и иных косвенных налогов; перед закупкой необходимо запросить коммерческое предложение.

## Что используется

Verifier вызывает `CadesVerifyDetachedMessage()` из `libcades.so` и при сборке связывается с `libcades` и `libcapi20`.

```text
verifier -> CryptoPro CAdES SDK -> CryptoPro CSP
```

- **КриптоПро ЭЦП/CAdES SDK** разбирает CMS/CAdES и реализует процедуру создания и проверки подписи. SDK [распространяется свободно](https://cryptopro.ru/products/cades), но не является самостоятельным криптопровайдером.
- **КриптоПро CSP** выполняет операции ГОСТ, работает с сертификатами, цепочками доверия и хранилищами. Для текущего verifier CAdES SDK используется поверх CSP и без установленного CSP не работает.

Наличие официального дистрибутива или Docker-образа не предоставляет лицензию на промышленное использование.

## Что сейчас не требуется

- **Лицензия на ГОСТ TLS-сервер** не нужна, пока HTTPS завершается обычным nginx, ingress или load balancer и CSP не используется для ГОСТ TLS.
- **CryptoPro OCSP Client и TSP Client** не нужны для текущей проверки detached CAdES-BES на текущее время. Они потребуют отдельной оценки при добавлении формирования или расширенной обработки CAdES-T/LT/LTA.
- **`cryptcp`** не используется: verifier вызывает C API напрямую.
- **CryptoPro SVS** не нужен: это отдельный готовый серверный продукт, а не зависимость нашего сервиса.

## Контейнеры и эксплуатация

Серийный номер нельзя записывать в `Dockerfile`, слой образа или репозиторий. Его следует передавать при развёртывании через защищённый секрет и активировать CSP согласно эксплуатационной документации. Для нескольких серверов, VM, Kubernetes-узлов или параллельных экземпляров схему лицензирования нужно письменно согласовать с КРИПТО-ПРО: документация определяет лицензию «на сервер», но не описывает нашу конкретную топологию контейнеров.

Тестовый запуск без production-лицензии не является основанием для промышленной эксплуатации: операции проверки могут технически выполняться и при отсутствии активированной лицензии.
